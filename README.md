# Martial Training Lab

A local-first martial-arts training game prototype rebooted from the old Biotact project.

## Current checkpoint — Training Arena
The product now combines:
- MediaPipe pose tracking in a Web Worker,
- adaptive personal strike calibration,
- quality gating,
- wrist-speed and trajectory analysis,
- punch-event detection,
- deterministic candle physics/scoring,
- interactive Three.js candle, shader flame, light and smoke,
- concise measured coaching,
- four training levels,
- five-strike rounds with success count and round summary,
- local recent-attempt history,
- desktop/mobile Chromium acceptance,
- visual screenshots and browser-run video saved as CI artifacts.

This is still a training prototype: camera-derived values are estimates; impact force is not claimed, and physical candle calibration remains pending.
