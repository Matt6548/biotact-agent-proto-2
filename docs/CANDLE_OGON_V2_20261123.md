## Что изменено (только существующий WebGL/Three.js)

| Проблема preview | Изолированное решение |
| --- | --- |
| Геометрически чёрная тень слева от подставки | Убрана направленная карта теней; под подставкой одна мягкая двухмасштабная контактная тень на плоскости, без self-shadow artifact |
| Тёмный овальный стол | Вместо маленького круга — большая плоскость с дешёвым исходным GLSL световым пятном (не внешняя текстура), плавное янтарное ослабление по расстоянию |
| Симметричная нарисованная «капля» | Независимый изогнутый центр + несимметричная ширина, анимированный верх, полупрозрачные crossed shells и центр hot core; синее основание у фитиля |
| Недостаточный тёплый свет на воске | Один PointLight ниже и немного перед пламенем, краткое изменение яркости, тепло-золотистый верх воска |
| Слишком идеальный цилиндр | Три локальных потёка внутри существующей сетки, мягкая неоднородность цвета (без текстур), сохранена впадина вокруг фитиля |
| Вопрос о мобильной стоимости | ShadowMap выключен, добавлено +2 лёгких flame sheets; динамика в существующем RAF; новый shader только на столе, нет постпроцессинга или второго renderer |
| Не было измеримого бюджета | `canvas.candleRenderStats()` возвращает количество draw calls, triangles, geometries, textures, effective DPR, состояние живого огня. Метод удаляется при dispose |

Визуальный свет и поведение являются художественной аппроксимацией. Камера **не** измеряет воздушный поток или физическую силу удара.

## План проверок и признаки готовности

1. `npm test`: проверка существующей логики плюс три новых unit-теста — цвет/потёки воска; layered shader + relight; read-only metrics + освобождение ресурсов без повторной утилизации.
2. `npm run build`: совместимость с Three.js 0.186.1 и существующей Vite/MediaPipe интеграцией.
3. `npx playwright test --project=candle-visual-chromium`: синтетическая, без камеры, съёмка `candle-360.png`, `candle-390.png`, `candle-1366.png`, `candle-1440.png`. Проверки canvas/DPR/overflow/shader console/active flame/draw-call bounds и `candle-render-metrics.json`.
4. GitHub Actions `OGON candle visual evidence` загружает скриншоты и метрики в **arton-only PR evidence**; пользовательские/камерные фотографии владельца туда не попадают.
5. BOSH сравнивает сцену с приватным визуальным обзором, **не копируя** пользовательские скриншоты.
6. Перед релизом на Redmi Note 9S в течение 60 секунд: реальная частота кадров, падение кадров, нагрев, динамика пламени, сохранение движения при освещении. Это **не подменяется** результатом headless Chromium.

### Честное разделение evidence

- **Исходное подтверждение:** интеграционный PR #6 / HEAD `9f94544`, предыдущий GitHub Actions CI в PR #6: 98/98 node, 11 Playwright, build PASS (по отчёту BOSH). Эти показатели **не относятся автоматически к этой итерации**.
- **Новая итерация:** отдельная проверка в GitHub Actions с артефактами. До завершения CI результат **NOT YET VERIFIED**.
- **Draw calls / GPU load:** `renderer.info` отражает количество вызовов отрисовки и треугольников, не GPU time. `pixelWidth * pixelHeight` можно использовать лишь для сравнения размера кадра, не как замер нагрузки GPU.
- **Headless FPS:** отображаемый в JSON FPS — браузерный rAF на GitHub Ubuntu; это НЕ FPS Redmi Note 9S и не физическое время GPU.
- **Лицензирование:** весь GLSL/геометрия оригинальные, референсы SmokeGL и fire-shader имеют MIT. Внешние текстуры/исходники/ассеты не переносились.
