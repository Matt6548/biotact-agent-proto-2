# Игра со свечой — BOSH интеграционный черновик (21.11.2026)

## Цель

Одна свободная тренировка без имени, обязательного onboarding, глав, уровней,
таймера, пятиударных раундов и автоматического завершения. Пользователь сразу
видит свечу и сам нажимает «Начать упражнение». Обучение/рейтинги — только
отдельные будущие опции по решению владельца.

## Совмещение и решение конфликта

- Новый `FreePracticeCameraController` владеет камерой и CV-трекингом в реальном
  сеансе; `FreePracticeEngine` считает движения без раундов, оценивает только
  **относительный визуальный отклик** и ограничивает память 16 пиками.
- Событие движения получает один transient `frame` для вывода позы и локальной
  технической диагностики; движок кадры не сохраняет.
- Пауза освобождает видеотреки и worker, продолжение запрашивает камеру заново,
  выход со вкладки также выключает камеру. Автоматического возобновления нет.
- Пламя обновляется по `response` движка и плавно восстанавливается с шагом
  около 50 мс только во время активной тренировки. Повторное зажигание не
  завершает сеанс.
- Существующие simulation/trace/field-test панели остаются отдельной скрытой
  инженерной функцией. Устаревшие раунды не участвуют в пути реальной камеры.
- PR #3 и PR #4 оба добавляли `tests/free-practice.test.js`: тесты объединены,
  500-ударный regression BOSH сохранён вместе с CV-циклами/защитами.
- PR #5 добавил новый рендерер, геометрию, GLSL и E2E на 360/390/1440 без
  дополнительных зависимостей. Внешний код/ассеты SmokeGL/fire-shader не
  копировались (см. отчёт ОГОНЬ).

## Что проверить до публикации

1. Desktop 1440 и mobile 360/390: красивая свеча, нет overflow, мини-камера
   не перекрывает пламя, видны кнопки «Пауза»/«Завершить».
2. Camera grant/deny/потеря модели, pause → stream tracks/worker остановлены,
   resume → новая камера, stop → снова готовность к началу.
3. 100+ синтетических и настоящих движений не завершают упражнение; дрожание,
   закрытая рука, пропуск кадров не создают ложных ударов.
4. На Redmi Note 9S Android 11: 60+ секунд тренировки, движение перед камерой,
   погасить и повторно зажечь, пауза, блокировка/возврат, температура и FPS.
5. Просмотр владельцем 3D-огня и нового UX. Только затем решать вопрос о
   тестовом preview/deploy и отдельном производственном обновлении.
