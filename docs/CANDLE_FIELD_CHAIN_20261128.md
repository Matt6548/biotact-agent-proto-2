# BOSH — desktop field chain QA
Baseline e565418c20fc6c7f4e1279f498446eebba766399, four integrated CI workflows passed, published preview 0445706a6acf238d69e77350920b323bbd83b284 READY. The old field UI test used a fake camera without a detectable hand, while actual-model gesture tests used a separate harness. This PR bridges that gap with a public-image canvas camera stream and the actual production Hand CPU worker, analyzer, existing WebGL candle and UI. No product source or production configuration changes.
The test requires a real detected hand, 65 seconds of stationary active camera with no confirmed events, at least one confirmed response in three time-defined scale pulses, no double events, blank-frame rejection, explicit camera stop, one WebGL canvas, no external requests or worker privacy attempts. It retains numeric evidence including missed pulses and observed inference timestamps; no camera media or coordinates saved. No claim of actual human accuracy, physical camera behavior, pixel-level visual quality or optical motion-to-display latency. A failed gate is a result, not a reason to bypass assertions. Real desktop and phone acceptance still required.
