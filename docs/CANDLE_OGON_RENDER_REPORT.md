# ОГОНЬ — визуальный рендер свечи

Дата: 2026-11-20. Ветка: feature/ogon-candle-visual-20261120.
Интеграционная база: martial-training-lab. Не менять production и не сливать без просмотра владельцем.

## Изменения

Все изменения остаются в существующем Three.js-компоненте; src/main.js и src/style.css не редактировались.

| Элемент | Раньше | Теперь |
| --- | --- | --- |
| Воск | Правильный цилиндр с плоской крышкой | Одна процедурная сетка из 1 315 вершин / 2 520 треугольников: лёгкая неоднородность поверхности, оплавленный край, вдавленная лунка |
| Фитиль | Прямой цилиндр | Тонкая изогнутая обугленная нить с тлеющим кончиком |
| Пламя | Одна плоская маска, почти постоянная ширина | Заострённая маска с синим основанием, янтарной оболочкой, светлым ядром; отдельно слабое свечение |
| Свет | Статическая основа + пульсирующая точка | Сдержанное мерцание с плавным угасанием, подсветкой воска, мягкой тенью и подставкой |
| Дым | 34 отчётливые точечные частицы | 28 мягких полупрозрачных точечных спрайтов, расширение и затухание по мере подъёма после угасания |
| Удар | Волна точек + отклонение шейдера | Дополнительное короткое возмущение пламени и света; визуальная «воздушная» волна менее навязчива |
| Отрисовка | 1024² карта теней | 512²; DPR ограничен 1.35 на узких контейнерах, не выше запрошенного cap |

Эффекты физически вдохновлённые, а не измерение реальной силы удара или воздушного потока. API setState/triggerImpulse/reset/setActive/dispose сохранён для BOSH.

## Проверка источников и лицензий

- [SmokeGL — Luca Angioloni и Francesco Pegoraro](https://github.com/LucaAngioloni/SmokeGL): **MIT**, частицы огня и дыма, Three.js, WebGL; полезен как концепция локального движения. Исторический код не импортировали.
- [fire-shader — cpl121](https://github.com/cpl121/fire-shader): **MIT**; идеи заострённой маски, мягких краёв и низкочастотного возмущения. Проект на React Three Fiber/Next.js не импортировали.
- Для этого PR не копировались внешние код, материалы или ассеты. Весь новый GLSL и mesh написан для нашего рендерера; внешнее ПО/лицензии в бандл не добавлены.

### Как получить реальные кадры

1. На машине с Chromium: npm ci → npm run build → npx playwright install chromium.
2. В исходной ветке martial-training-lab запустить существующий smoke test, он уже сохраняет исходный кадр 01-initial.png для desktop и mobile.
3. В этой ветке запустить npx playwright test --project=candle-visual-chromium. Три размера будут сохранены в test-results/.
4. Сопоставить одинаковый участок свечи, освещение, масштаб, отсутствие дрожания и артефактов. Сверить 60 секунд на физическом Redmi Note 9S до интеграции.

### Приёмка для BOSH

- Только один активный WebGL-рендер на телефоне (существующий контроллер оставлен как есть).
- Проверить на телефоне, что огонь не выглядит плоским, воск не мерцает, контур свечи не исчезает при повороте и дым появляется только после угасания.
- Проверить повторный запуск/reset/релайт после удара и утечки ресурсов при появлении/исчезновении миниатюры.
- Скриншоты и полевой просмотр владельцем — **обязательны перед merge**.
